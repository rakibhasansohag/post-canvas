# Post Canvas

A rich-text editor for posts and articles, built on [Tiptap](https://tiptap.dev). It adds a media canvas to the usual
formatting: photo galleries (carousel, grid, masonry and collage), video and social embeds, link cards, a `+` insert
button and drag-to-reorder blocks.

Work in progress: the first release is being built. The package lives in [`package/`](package) and the docs site in
[`client/`](client).
